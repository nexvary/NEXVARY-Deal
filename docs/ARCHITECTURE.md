# Architecture

- Android: Kotlin / Jetpack Compose (planned)
- Backend: FastAPI (initial read-only API)
- Database: PostgreSQL (planned)
- Scheduled jobs: Redis / Celery (planned)
- Provider connectors: official APIs and permitted public sources only (planned)
- Verification levels: official, tested, community, unverified
- Admin interface, user accounts, notifications, deployment and Android APK are not yet implemented.

Never claim a coupon is tested without a documented checkout/API verification. Avoid prohibited scraping, credential collection and secret exposure. All external redirects should be validated and affiliate relationships disclosed.
